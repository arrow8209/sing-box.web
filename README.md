# SingBox Control 原型

这是一个零依赖、可直接预览的 sing-box Web 控制台交互原型，包含：

- 仪表盘与核心运行状态
- 自定义配置 A：通用、入站、出站、路由与 DNS 配置
- 新增入站会按类型显示专属字段，“自定义”类型支持输入、校验和再次编辑完整 JSON 对象
- TUN 入站支持堆栈、自动/严格路由、端点独立 NAT、MTU 与多组 IPv4/IPv6 路由地址
- 出站支持直连、阻断、手动选择和自动选择，并可配置筛选条件、测速参数及引用的出站与订阅节点
- 路由设置在单页中集中展示通用参数、规则集与有序规则，并支持按规则类型和动作编辑专属参数
- 订阅配置与同步操作
- 规则集管理
- 系统与界面设置

## 本地预览

```bash
npm run dev
```

然后访问 <http://localhost:4173>。也可以直接在浏览器中打开 `index.html`。

当前页面使用演示数据，按钮、导航、主题切换、弹窗、配置保存、订阅同步和规则集更新均提供原型交互，不会修改真实的 sing-box 配置。
